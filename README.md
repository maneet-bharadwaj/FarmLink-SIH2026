# FarmLink – SIH 2026

FarmLink is a smart farmer-to-market platform that helps farmers compare market prices, buyers, selling costs, and estimated net returns.

## 🚀 Live Prototype

https://farmlink-smart-marke-awaz.bolt.host

## 🎯 Key Features

- Farmer dashboard
- Crop listing
- Market comparison
- Net-return calculation
- Buyer discovery
- Buyer connection
- Sale tracking
- Price trends

## 🏆 Smart India Hackathon

**Problem Statement:** SIH26132  
**Theme:** Agriculture, FoodTech & Rural Development  
**Category:** Software

## 💡 Core Idea

FarmLink converts scattered market information into one clear selling decision by helping farmers compare available selling opportunities based on expected price, selling costs, distance, and estimated net return.

## 🔄 Farmer Journey

1. Login to FarmLink
2. List the crop
3. Discover markets and buyers
4. Calculate estimated net return
5. Connect with the selected buyer
6. Track the sale
